mist is installed in namespace {{ .Values.namespace }}.

1. Create the default monitor so the operator renders the agent DaemonSet:

     kubectl apply -f - <<EOF
     apiVersion: mist.io/v1
     kind: TrafficMonitor
     metadata:
       name: default
       namespace: {{ .Values.namespace }}
     EOF

   (Defaults: all namespaces, 5s drain interval. The DaemonSet appears as
   mist-agent once the operator reconciles.)

2. Check the rollout:

     kubectl -n {{ .Values.namespace }} get trafficmonitors,anomalyalerts,daemonset,pods

3. Read the API (port-forward, then open or curl):

     kubectl -n {{ .Values.namespace }} port-forward svc/mist-api 3000:3000
     curl localhost:3000/healthz            # -> ok
     curl localhost:3000/metrics | head -20 # public Prometheus scrape

   REST needs a login token (seeded from api.adminEmail/adminPassword;
   empty values fail login closed — see values.yaml):

     TOKEN=$(curl -s -X POST localhost:3000/api/auth/login \
       -H 'content-type: application/json' \
       -d '{"email":"...","password":"..."}' | \
       python3 -c 'import json,sys; print(json.load(sys.stdin)["token"])')
     curl -H "authorization: Bearer $TOKEN" localhost:3000/api/alerts

   Dashboard: http://localhost:3000/login with the same credentials.

4. Watch live events over the WebSocket (token in ?token=):

     # any WS client against "ws://localhost:3000/api/ws?token=$TOKEN"
