mist is installed in namespace {{ .Values.namespace }}.

1. Create the default monitor so the operator renders the agent DaemonSet:

     kubectl apply -f - <<EOF
     apiVersion: mist.io/v1
     kind: TrafficMonitor
     metadata:
       name: default
       namespace: {{ .Values.namespace }}
     EOF

   (Defaults: all namespaces, 5s drain interval. The DaemonSet appears as
   mist-agent once the operator reconciles.)

2. Check the rollout:

     kubectl -n {{ .Values.namespace }} get trafficmonitors,anomalyalerts,daemonset,pods

3. Read the API (port-forward, then open or curl):

     kubectl -n {{ .Values.namespace }} port-forward svc/mist-api 3000:3000
     curl localhost:3000/healthz            # -> ok
     curl localhost:3000/api/flows | head -c 500
     curl localhost:3000/api/alerts

   No login is required: the API currently has no authentication
   (see the chart README/docs). Do not expose it beyond localhost.

4. Watch live events over the WebSocket:

     # any WS client against ws://localhost:3000/api/ws (see step 3 forward)
